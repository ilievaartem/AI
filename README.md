# Fashion MNIST Deep Learning Project

## Сучасні технології Deep Learning

Цей проект реалізує повний аналіз класифікації Fashion MNIST з використанням нейронних мереж TensorFlow/Keras, включаючи оптимізацію гіперпараметрів та детальний звіт.

## Структура проекту

- `fashion_mnist_deep_learning.py` - основний Python скрипт з повною реалізацією
- `Fashion_MNIST_Deep_Learning.ipynb` - Jupyter Notebook з інтерактивною версією
- `requirements.txt` - залежності Python
- `README.md` - цей файл з документацією

## Що реалізовано

### 1. Базова модель
- Завантаження та обробка Fashion MNIST
- Створення нейронної мережі з архітектурою:
  - Вхідний шар: 784 нейрони
  - Прихований шар: 800 нейронів (ReLU)
  - Вихідний шар: 10 нейронів (Softmax)
- Навчання протягом 100 епох

### 2. Тестування розпізнавання
- Розпізнавання конкретного зображення з датасету (n_rec=492 - сумка)
- Створення та тестування власних зображень предметів одягу
- Візуалізація результатів з розподілом ймовірностей

### 3. Експерименти з гіперпараметрами

#### 3.1 Кількість епох навчання
Тестування: 50, 75, 100, 125 епох
- Аналіз впливу на точність
- Порівняння часу навчання

#### 3.2 Розмір міні-вибірки (batch size)
Тестування: 50, 100, 200, 400
- Вплив на швидкість збіжності
- Оптимізація використання пам'яті

#### 3.3 Кількість нейронів у прихованому шарі
Тестування: 500, 700, 900, 1200 нейронів
- Вплив на здатність мережі до навчання
- Баланс між складністю та перенавчанням

#### 3.4 Додавання прихованого шару
Тестування додаткового шару з: 500, 700, 900, 1200 нейронів
- Перехід до глибокої архітектури
- Аналіз впливу на час навчання та точність

### 4. Оптимальна модель
- Комбінація найкращих гіперпараметрів
- Порівняння з базовою моделлю
- Рекомендації для подальшого покращення

## Результати

### Базова модель
Очікувана точність: ~87-89% на тестових даних

### Експерименти показують:
- Оптимальна кількість епох для уникнення перенавчання
- Вплив batch size на стабільність навчання  
- Важливість правильного розміру прихованих шарів
- Ефективність додаткових шарів для покращення точності

### Типові результати експериментів:
- **50 епох**: ~85-86% точності, менший час навчання
- **75 епох**: ~87-88% точності, збалансований варіант
- **100 епох**: ~87-89% точності, базова конфігурація
- **125 епох**: можливе перенавчання, аналогічна точність

- **Batch size 50**: повільніше навчання, більша стабільність
- **Batch size 100**: збалансований варіант
- **Batch size 200**: базова конфігурація (рекомендована)
- **Batch size 400**: швидше навчання, менша стабільність

- Висновками та рекомендаціями
- Пропозиціями для подальшого покращення

## Рекомендації для покращення

1. **CNN архітектура** - використання згорткових шарів
2. **Регуляризація** - Dropout, L1/L2 регуляризація
3. **Кращі оптимізатори** - Adam, RMSprop замість SGD
4. **Аугментація даних** - поворот, зміщення, масштабування
5. **Learning rate scheduling** - адаптивне налаштування швидкості навчання
6. **Batch normalization** - нормалізація між шарами
